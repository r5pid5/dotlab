폰트와 출처

요청한 글꼴은 이름이 비슷한 동명 폰트를 구분해 조사했습니다. 기본 제공 32개 글꼴과 직접 파일을 연결하는 7개 요청 글꼴이 있습니다. 개인용 이용 허용과 웹 서비스의 폰트 파일 배포 허용은 같은 조건이 아니므로, 제한이 있거나 근거가 부족한 파일은 사이트에 포함하지 않았습니다.

폰트 파일은 원본 형식을 유지합니다. 머니그라피는 토스 공식 서버의 웹폰트를 불러옵니다. 실제 브랜드·로고에서 HS잔다리체를 사용하는 경우 제작자 조건을 별도로 확인하세요. 아래는 이용 조건의 요약이며 원 배포처와 동봉 문서가 우선합니다.

글꼴제공 방식 / 이용 조건배포처

원문 안내

  • 던파 비트비트체 v2 저작권 안내
  • 카페24 슈퍼매직 라이선스
  • Math Donuts 제작자 안내, Floozy 제작자 안내
  • Google Fonts의 10개 영문 글꼴과 기랑해랑체는 각 파일과 함께 OFL 문서를 보관합니다. Noto Color Emoji OFL, Pretendard OFL

케리스 케듀체는 사용자가 적어준 ‘캐리스케듀체’, 김씨 와일드각체는 ‘김씨와일드각제’에 해당하는 것으로 판단한 이름입니다. 속초시·문경시·일부 블로그의 원문 접근에는 제한이 있어 공개 웹폰트 배포 기록도 함께 확인했습니다. 사용 조건이 불확실한 부분은 글꼴 서랍에 별도 표시했습니다.

기술과 모델

  • BiRefNet Lite 512 · 사진/사물 누끼 · MIT
  • SkyTNT Anime Segmentation · 캐릭터 누끼 · Apache 2.0. 여러 방향으로 분석한 결과를 합치는 기능을 추가했습니다. 모델 가중치는 변경하지 않았으며 파일만 분할했습니다. 고정 버전·원본·SHA-256
  • ONNX Runtime Web · MIT
  • U²-Net, rembg Silueta 피사체 분리 모델 · Apache 2.0 안내
  • MediaPipe Face Detector · Apache 2.0
  • gifenc · MIT
  • fflate · MIT

이미지와 템플릿

편집기는 빈 화면으로 시작합니다. 사용자 참고 사진은 GitHub 배포물에 포함하지 않습니다. 카메라·레이스·장식 프레임 자산은 이 작업을 위해 새로 생성했습니다. 템플릿과 효과 코드는 독립적으로 구현했습니다. WalkColor 및 dooo0t와 제휴한 서비스가 아닙니다.
